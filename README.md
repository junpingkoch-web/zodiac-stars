# Zodiac & Stars

A free, static (no build step) calculator for Chinese zodiac sign and Western
star sign, based on birth date. Trilingual UI: 中文 / English / Deutsch.

## Run locally

Just open `index.html` in a browser, or serve the folder with any static
server, e.g.:

```
npx serve .
```

## Structure

Single-file app: all HTML/CSS/JS lives inline in `index.html` (no separate
`style.css`/`script.js`) — this is deliberate, see `CLAUDE.md`.
